# Laundry & Dry Cleaning Management System - Frontend

This is the frontend application for a Laundry & Dry Cleaning Management System MVP. It provides an intuitive user interface for managing laundry and dry cleaning services.

## Tech Stack

- React.js with TypeScript
- Modern React patterns and hooks
- Type-safe development with TypeScript
- REST API integration with backend

## Getting Started

### Prerequisites

- Node.js (v14 or higher recommended)
- npm or yarn
- Backend service running (see backend README)
